# Node.js Architecture Labs

This book accompanies three web applications implemented across six architectural
variants. It is written for an experienced Python or Go developer who wants a
precise mental model of JavaScript and Node.js before adopting increasingly
structured designs.

The curriculum treats architecture as an experiment. Each variant keeps the
domain and observable behavior recognizable while changing one principal design
idea. Tests and reflections make the tradeoffs visible.
