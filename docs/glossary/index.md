# Glossary

- **Adapter** — an implementation that translates an external technology into
  a port used by application code.
- **Aggregate** — a domain consistency boundary with one root through which
  state changes are performed.
- **Composition root** — the place where concrete dependencies are assembled.
- **Domain event** — an in-process representation of a meaningful business fact.
- **Port** — an application-owned capability contract.
- **Promise** — an object representing a future fulfillment or rejection.
- **Use case** — an application workflow independent of a transport protocol.
- **Value object** — an immutable value defined by its attributes rather than a
  database identity.
